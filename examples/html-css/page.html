qui a lightweight HTML + CSS engine, in Go

Every pixel below is real HTML parsed by golang.org/x/net/html, styled with real CSS, and rendered into the retained qui widget tree — no browser, no WebView. Read more in the project docs.

<select> option 语义 · type=search 清空按钮 NEW

<option value> 是**提交值**（不是可见文字）、selected 设初选、 disabled 灰掉不可选、<optgroup label> 变成不可点的分组标题行； 聚焦后**敲字母**可跳到匹配项（连敲同一字母循环）。 type=search 有内容时右侧出现 UA 清空按钮，type=number 有步进器， <input list> + <datalist> 是**原生补全**（不是组件库的 filterable）。
